# IITK_AIML

Course work from the IITK AIML program.

## IITK AIML Foundations Programming Refresher

### Personal Expense Tracker

Python menu program. You log expenses, view them, check a monthly budget, and store the list in `expenses.csv`.

```bat
cd "IITK AIML Foundations Programming Refresher\personal_expense_tracker"
python personal_expense_tracker.py
```

Menu:

1. Add expense
2. View expenses
3. Track budget
4. Save expenses
5. Exit

Write-up and run screenshots are in that folder.

### Task Manager with User Authentication

Python menu program. You register, log in, then add / view / complete / delete tasks. Credentials sit in `users.json` (hashed). Tasks sit in `tasks.json` per user.

```bat
cd "IITK AIML Foundations Programming Refresher\task_manager_with_user_authentication"
python task_manager_with_user_authentication.py
```

Auth menu: Register, Login, Exit.

After login: Add a Task, View Tasks, Mark a Task as Completed, Delete a Task, Logout.
